# Zylora — Diversity, Density, Contrast & Signature Refinement

## Scope
Focused catalogue refinement of the 21 code-reference templates based on visual review feedback. This is not a full-product audit.

## Structural diversity corrections
The earlier shared-layout families were split into distinct composition systems:

- 01 Orbit Craft — kinetic type / offset photo / marquee / accordion / stacked process cards.
- 02 Prompt Atelier — studio index / latest-signal rail / sector bento / lab grid.
- 06 Depth Studio — lavender editorial / clipped image band / staggered project panels / spectrum list.
- 07 Grid Foundry — print-poster system retained.
- 08 Oblique House — vertical side rail / full dark identity composition / system rows / geometric poster.
- 09 Shipyard Labs — engineering console / engagement cards / case log / decode diagram.
- 10 Syntax Field — terminal-led developer portfolio retained as a separate code-centric system.
- 11 Grounded Form — architecture-led project register retained.
- 12 Civic Rise — housing ledger / site-stage table / portfolio numbers.
- 15 Site Pilot — contained rounded hero / single-sprint plan card / checklist model.
- 16 Launch Desk — dark queue-based workflow / support board / weekly cadence.
- 17 Newmark Bureau — brand thesis / lime orbital device / services ledger / principle cards.
- 18 Immersive Stack — cinematic full-bleed frame / horizontal project rail / dual practice split.
- 19 Oddframe — campaign poster / circular photo / tape rail / physical-card stack / film-strip graphics.
- 20 Harvest House — historic hospitality editorial / seasonal strip / room settings / FAQ system.
- 21 Laurel Studio — awards ribbon / honors ledger / client quote / performance metrics.

## Text-density normalization
- Long repeated card descriptions were shortened in the high-density creative/portfolio templates.
- Comparable card systems now target roughly one compact supporting statement per card rather than paragraph-length copy.
- Sparse verticals retain more breathing room where the reference/business type calls for it; density is no longer being forced to be identical across unrelated industries.

## Contrast corrections
Templates 09 and 10 now use brighter secondary text on dark surfaces and stronger divider colors. Small descriptive rows use `#c7cfcd` against near-black `#0d0e0f`, rather than low-opacity gray.

## System signature
A small circular black arrow badge is now part of the navigation identity across all 21 templates. It is intentionally subtle: recurring enough to feel like a Zylora catalogue signature, but not large enough to make unrelated templates share the same composition.
