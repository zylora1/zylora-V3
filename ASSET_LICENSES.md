## New template admission rule

A template may be added as a source-exact implementation only when its source code is explicitly open-source and the license permits modification and redistribution.

For an admitted open-source template, Zylora preserves the original layout, spacing, typography treatment, animation choreography, scroll animation, hover behavior, responsive behavior, and interaction timing. Only content and colors are changed by default.

Assets are retained only when their license also permits redistribution. Non-redistributable imagery or brand assets must be replaced by properly licensed real assets while preserving the original placement, crop geometry, and composition.
