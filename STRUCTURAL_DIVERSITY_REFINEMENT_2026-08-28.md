# Zylora — Structural Diversity Refinement

## Scope
Focused refinement of the 21 reference-derived templates based on visual-comparison feedback. This is not a whole-product production audit.

## Near-duplicate clusters rebuilt
- Reference #07 `Grid Foundry`: rebuilt as a Swiss/editorial modular print grid with vertical rail, asymmetric project mosaic, four-column capabilities band and geometric manifesto.
- Reference #08 `Oblique House`: rebuilt as a dark cinematic identity portal with centered portrait aperture, project ledger, radial capability system and serif manifesto.
- Reference #15 `Site Pilot`: rebuilt as a light operational/bento managed-site service with live project board, process bento, deliverables table and scoped engagement card.
- Reference #16 `Launch Desk`: rebuilt as a dark website-operations queue with request board, status rail, monthly cadence and support cards.
- Reference #17 `Newmark Bureau`: rebuilt as a radial futurist brand-transformation system with orbit diagram and transformation ledger.
- Reference #19 `Oddframe`: rebuilt as a playful advertising/storyboard system with campaign frames, reel strip and performance-oriented service table.

## Content-density normalization
- Shortened repeated card copy in the densest creative/product templates.
- Added subject-specific decision copy to the previously sparse housing and hospitality service cards.
- Target is consistent visual density, not identical word count across unrelated business types.

## Contrast hardening
Reference-order #09 `Shipyard Labs` and #10 `Syntax Field` received higher-opacity small text and stronger divider values on dark rows.
- Dark service-row background: approximately `#0d0e0f`.
- Effective small body copy after opacity blending: approximately RGB `(193, 194, 189)`.
- Calculated contrast ratio: approximately **10.75:1**, above WCAG AA/AAA thresholds for normal text.

## System signature
A shared black circular arrow badge is now present across all 21 templates as a small catalogue-level signature. It is intentionally limited to this utility motif; layout structures remain independent.
