## Fidelity rule for future open-source template imports

When a supplied template is explicitly open-source and its license permits modification and redistribution, preserve its visual and behavioral implementation exactly: layout, component geometry, spacing, typography treatment, responsive composition, hover states, transitions, animations, scroll choreography, and interaction timing. Change only the site content and color values unless a technical or licensing constraint makes an exact carry-over impossible.

Awwwards listing pages are reference indexes, not open-source licenses. A site must be individually verified before source-exact reuse.
