# Editorial Neon Yellow

Reference-driven single-page creative portfolio template.

- Uses only the real images supplied by the user.
- No AI-generated photographs or illustrations are bundled.
- Graphic accents (yellow blocks, dots, crosses, checker/grid motifs) are built in CSS.
- Responsive layouts included for desktop, tablet and mobile.

## v1.1 surface refinement
- Added procedural print/photocopy grain and subtle scan-line texture.
- Increased photographic contrast and ink-like density to better match the supplied editorial reference.
- No AI-generated imagery was added.
