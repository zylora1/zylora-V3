# TXT 1–35 open-source asset policy

The 35 templates added from `TEMPLATES.txt` use only real photographic source material already available locally from verified open/free sources: audited Pexels photographs and CC0/public-domain photographs distributed with scikit-image. No AI-generated photograph or hotlinked runtime media is used. Each template owns its local `hero.webp` and its own `ASSET_LICENSES.md`.

Because the execution environment blocks new remote image-byte downloads, some closely related design/technology references reuse the same verified source photograph with a different art-directed crop. This is explicit in each template's license record rather than being hidden.
