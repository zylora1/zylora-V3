# Design Reference and License Posture

This catalogue uses external design ecosystems as research/reference points, not as a source of copied marketplace template code.

## Reference sources

- shadcn/ui — https://github.com/shadcn-ui/ui — MIT.
- Magic UI — https://github.com/magicuidesign/magicui — MIT.
- HyperUI — https://github.com/markmead/hyperui — MIT.
- Preline UI — https://preline.co/docs/license.html — dual MIT / Preline UI Fair Use terms. Zylora treats Preline primarily as design/information-architecture inspiration for this redistributable template catalogue rather than copying Preline Pro/template source.
- React Bits — https://github.com/DavidHDev/react-bits — MIT + Commons Clause. Zylora treats React Bits as motion/interaction inspiration rather than redistributing React Bits components in the template catalogue.
- Aceternity UI — https://ui.aceternity.com/licence — marketplace/template redistribution restrictions apply to Aceternity items. Zylora uses Aceternity only as visual/micro-interaction inspiration and does not bundle Aceternity item source code into these templates.
- Refero / contemporary editorial, hospitality, architecture, product, agency, and portfolio websites — visual research only; no proprietary page was cloned.

## Implementation rule

The production templates in this repository are original TSX/CSS implementations. No third-party component source from a license that prohibits template/marketplace redistribution is intentionally bundled into the catalogue. Infrastructure dependencies remain governed by their own package licenses.

When future contributors introduce third-party code, they must check the current upstream license, preserve required notices/attribution, and avoid incorporating assets or source whose terms are incompatible with Zylora's downloadable/source-export template model.
